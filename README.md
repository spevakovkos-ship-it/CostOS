# CostOS cpp

![C++ Version](https://shields.io)
![Platform Support](https://shields.io)
![Architecture](https://shields.io)

A hobbyist CLI console operating system emulator written in C++. **CostOS** features a modular architecture that separates hardware-level configurations (**BIOS**), the core system interface (**Shell**), and specialized functional environments (**Math Module**).

---

## Key Features

*   **Dual-Layer Architecture:** Pure separation between BIOS configurations and Shell execution environments.
*   **Interactive Bootloader:** Prompts the user on startup to either boot directly into the OS or access the BIOS setup via the `DEL` key.
*   **Virtual BIOS Configurator:** Reads and writes system variables (like toggling mathematics mode or error logging) dynamically to a persistent configuration file.
*   **Advanced CLI Shell:** Supports text-tokenization with an arguments parser, role-based user access levels (`USER`, `ROOT`, `SYSTEM`), and ANSI color codes formatting.
*   **Dedicated Math Subshell:** An isolated runtime shell environment triggered by `mathMode` that modifies the system prompt and enables computational algorithms.

##  Built-in Shell Commands

###  Core OS Commands

| Command | Arguments | Description |
| :--- | :--- | :--- |
| `clear` | — | Clears the terminal screen buffer (`cls` / `clear`). |
| `print` | `<text1> [text2] ...` | Prints single or multiple space-separated string arguments. |
| `colorPrint` | `<Color> <text1> ...`| Prints text in ANSI colors (e.g., `Red`, `Green`, `Cyan`, etc.). |
| `mathMode` | — | Launches the math subshell interface (if enabled via BIOS settings). |

###  Math Subshell Commands (Accessible via `mathMode`)

| Command | Arguments | Description |
| :--- | :--- | :--- |
| `calc` | — | Prompts for a classic infix math expression (`num1 op num2`) supporting `+`, `-`, `*`, `/`, `%`. |
| `getRandNum` | — | Generates a cryptographically-seeded pseudo-random integer within a custom min/max range. |
| `sum` | — | Accepts a space-separated list of integers and returns their sum. |
| `avg` / `average` | — | Accepts a space-separated list of integers and computes the exact mathematical mean. |
| `clear` | — | Clears the subshell terminal workspace. |
| `exit` / `q` / `quit` | — | Safely exits the math environment and restores the main OS prompt pointer. |

## Architectural Insights

### Type-Safe Config Visitor
The system utilizes `std::variant` along with member pointers and `std::visit` to safely match parameters from `BIOS/Config.conf` into operational variables inside runtime:

```cpp
using BoolPtr = bool BIOS::*;
using IntPtr  = int BIOS::*;
using FieldPtr = std::variant<BoolPtr, IntPtr>;

// Dynamically unpacks and maps file variables
std::visit([this, &valueStr](auto&& field_ptr) {
    using T = std::decay_t<decltype(field_ptr)>;
    if constexpr (std::is_same_v<T, BoolPtr>) {
        this->*field_ptr = (valueStr == "true");
    } 
    // Handles numerical assignments seamlessly
}, it->second);
```
</details>

<details>
<summary> Click to view how Shell Commands Dispatcher works</summary>

### Member Function Pointers Map
Instead of heavy `if-else` branching, the Shell leverages an internal `std::unordered_map` consisting of string keys and direct member function pointer values:

```cpp
std::unordered_map<string, void (Shell::*)(const Args&)> commands;

// Direct execution call structure
auto it = commands.find(cmd);
if (it != commands.end()) {
    (this->*(it->second))(args);
}
```
</details>

<details>
<summary> Click to view how the Math Subshell interfaces with the OS</summary>

### Procedural Function Mapping & Prompt Lifecycle
The `mathInterface` takes a reference to the active `Shell` object to intercept its configuration variables. It mutates the state of the shell interface prompt on entry, binds standard functions via `std::unordered_map`, and safely wraps the calls into a structured `try-catch` block to handle exceptions like division by zero (`Zero divide`):

```cpp
using command = void(*)(void);
shell.INPUT1 = "Math -"; // Mutates the terminal prompt prefix

static const std::unordered_map<std::string, command> mathCommands = {
    {"calc", &calcCin},
    {"sum", &reduceCin},
    {"avg", &averageCin}
};

// Exception-safe execution loop
if (it != mathCommands.end()) {
    try {
        it->second();
    } catch (std::exception& err) {
        std::cout << "Error: " << err.what() << std::endl;
    }
}
```
</details>

##  Compilation & Build

### Prerequisites
*   A C++ compiler with **C++17** or above capabilities (`MSVC`, `GCC`).
*   `<conio.h>` library headers (Primarily targeted for **Windows** native console runtimes).

### Step-by-Step Native Build

1. Clone the repository setup:
   ```bash
   git clone https://github.com
   cd CostOS
   ```
2. Compile via your native compiler CLI tool (e.g., using `g++`):
   ```bash
   g++ -std=c++17 CostOSBoot/OSBoot.cpp modules/math_module.cpp -o CostOS.exe
   ```
3. Run the compiled system binary:
   ```bash
   ./CostOS.exe
   ```
